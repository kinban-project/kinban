# KINBAN AI運用ガイド

## 利用できる操作

運営支援AIはグループ専用キーを使い、シフト、勤務希望、勤怠、お知らせ、メンバー情報を運営補助のために確認できます。

変更操作は、グループ設定で許可されたものだけです。

1. シフト作成（割当下書きを含む）
2. シフト公開
3. 勤怠承認／差戻し（日次）
4. 勤怠承認／差戻し（月次）
5. お知らせ配信

## メッセージを処理する流れ

1. AIは `claim_next_assistant_message` で未処理メッセージを1件取得します。
2. 取得した `message.id` と `claimId` を対象メッセージの識別子・処理リースとして使います。短期トークンは不要です。
3. メンバーの問い合わせは、必要なシフトや勤怠を確認して返信、保留、完了に整理します。他メンバーの情報は返信に出しません。
4. 管理者がこのタスクへ直接指示した場合は、運営支援AIキーの発行者を指示者として、`sourceMessageId` と `claimId` なしで許可済みの変更操作を実行できます。メンバー問い合わせを処理中に管理操作を行う場合だけ、現在のclaimの `message.id` と同じ `claimId` を指定します。
5. 実行結果はKINBANの操作ログと運営AIのレポートに残します。

## 交代希望の扱い

メンバーからの欠勤・交代希望は、本人の割当を確認して返信や管理者確認待ちにできます。ただし、メンバーの依頼だけで全体お知らせを配信したりシフトを公開したりはしません。管理者が指示するか、別途自動配信を許可する運用ルールを定めてください。
