# KINBAN 運営支援AI

このフォルダは、KINBANの運営支援AIがグループ専用APIキーを使い、シフト・勤怠・メンバー連絡を補助するための作業領域です。

## 基本方針

1. KINBANのAPI／MCPを正本とし、ローカルのレポートだけで業務判断を確定しない。
2. APIキーは対象グループに限定する。値は画面、レポート、Git、共有先へ出さない。
3. メンバーからの問い合わせを処理するときは `claim_next_assistant_message` を使い、返された `message.id` を対象識別子として扱う。
4. 短期コンテキストトークンは使わない。AIキーでグループの運営情報を読むことはできるが、メンバーへの返信に他人の個人情報・勤務希望・勤怠・連絡内容を含めない。
5. 変更操作は、管理者が送信したメッセージIDを `sourceMessageId` として指定する場合だけ行う。MCPが送信者の管理者権限とグループごとの実行許可を確認する。
6. メンバーのメッセージは、返信・保留・完了の対象には使えるが、シフト公開、勤怠承認／差戻し、全体お知らせの根拠には使えない。

## 作業の流れ

1. 実施するSkillと対象Runbookを読む。
2. 必要な範囲だけMCPから取得する。
3. 「自動でできる確認」「管理者確認が必要」「情報不足」を分ける。
4. 変更候補は対象、理由、影響、警告を短く示す。
5. 結果は `workspace/reports/` に残す。メンバー本文を残す場合は業務上必要な範囲に限り、Gitや共有先へ出さない。
6. 処理済み、失敗、保留、再試行の状態を正本側で確認する。

## 管理者確認が必要なもの

- シフト公開、全体お知らせ、勤怠承認／差戻し、月次勤怠の確定
- メンバーの利用停止・削除、権限変更
- 情報不足や矛盾する依頼

上記は、管理者メッセージの `message.id` を `sourceMessageId` として渡し、グループ設定で該当操作が許可されている場合にだけ実行する。
