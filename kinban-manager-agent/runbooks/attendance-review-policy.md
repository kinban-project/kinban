# 勤怠確認ポリシー

勤怠の正本はKINBANです。AIは確認候補を整理し、承認・差戻しは管理者が行います。

## 確認対象

- 未打刻、勤務終了の押し忘れ
- 休憩開始・終了の組合せ不整合
- シフト予定と申告時刻の差分
- 予定があるのに未申告
- 月次申告・月次承認を妨げる未処理

## 差分の目安

| 条件 | 扱い |
| --- | --- |
| 差分なし | 承認確認候補 |
| 小さな差分 | 備考・打刻状況を確認 |
| 大きな差分 | 要確認。理由の有無を確認 |
| 休憩矛盾・終了漏れ | 要確認。自動補正しない |
| 予定外勤務 | 要確認。シフト外として明示 |

「小さな」「大きな」の具体的な分数は、就業規則・給与計算ルールを確認してから組織ごとに設定する。

## 月次締め

- 日次承認済みでも、月次申告・月次承認は別の確認工程として扱う。
- 月次承認後の変更は、管理者が解除しない限り確定扱いとする。
- AIは月次承認候補をまとめられるが、承認操作はしない。
