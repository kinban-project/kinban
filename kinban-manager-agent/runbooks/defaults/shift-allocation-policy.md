# シフト割当ポリシー

このファイルはテンプレート標準の判断基準です。組織固有のルールは `runbooks/local/` に追加してください。AIは、明記されていない厳格な制約を推測してはいけません。

## 現在の原則

1. 勤務不可を割り当てない。
2. 必要人数を満たせない場合は不足のまま表示し、理由を残す。
3. 同一時間帯に同じ人を複数担当へ重複割当しない。
4. 出勤希望、休み希望、曜日別の基本希望、今回コメントを参照する。
5. 希望外の割当、連勤、勤務時間の偏りは警告として示す。
6. 期間限定コメントは参考情報であり、自動の禁止条件にはしない。

## 組織固有の設定欄

| 項目 | 値 | 補足 |
| --- | --- | --- |
| 連勤の目安 | 未設定 | 例: 5日以上は要確認 |
| 1週の勤務時間目安 | 未設定 | 例: 40時間超は要確認 |
| 最低インターバル | 未設定 | 法令・就業規則を確認 |
| 担当別の必須資格 | 未設定 | 資格情報を扱う場合は別途設計 |
| 優先する希望 | 未設定 | 例: 勤務不可 > 休み希望 > 出勤希望 |

## 公開前チェック

- 担当・時間ごとの必要人数と割当人数
- 不足枠、重複割当、勤務不可割当
- 希望外割当と今回コメントの未確認
- メンバー別の勤務日数・時間・連勤
- 管理者がプレビューを確認した記録
