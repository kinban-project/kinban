# メンバー連絡ポリシー

## 回答の原則

- 丁寧で短く、確定していないことは「確認中」「管理者確認が必要」と明示する。
- メンバー本人の情報だけを使う。別メンバーの希望、勤怠、連絡内容を出さない。
- 管理者メモ、評価、内部判断、APIエラー詳細を開示しない。

## 文案として作成してよいもの

- 希望受付の期限案内
- 公開済みシフトの見方
- 勤務申告の入力方法
- 情報不足時の確認質問

## 管理者確認へ回すもの

- 欠勤、遅刻、早退、急な交代
- シフト変更の確定依頼
- 勤怠の修正、承認、差戻し
- ハラスメント、個人情報、トラブル、権限に関する問い合わせ

定型回答は、現在claim中の対象メッセージに限り送信できる。管理者判断が必要な内容は `needs_review` にして、管理者メッセージを根拠とする別の操作へ回す。
