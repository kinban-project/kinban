# KINBAN 運営支援AI: 直接指示モード

運営支援AIキーを発行できるのは、グループの代表管理者または管理者です。
そのため、キーを使ってChatGPT/Codexのタスクから直接実行する場合は、キーの発行者を指示者として扱います。

## 直接タスク

- グループ専用の運営支援AIキーを使う。
- `sourceMessageId` と `claimId` は指定しなくてよい。
- サーバーは、キーの発行者が現在も有効な代表管理者または管理者であることを毎回確認する。
- グループ設定で許可されている操作だけを実行する。
- `confirm: true` など、各ツールが要求する確認項目は省略しない。

## メンバーからの問い合わせ処理

- `claim_next_assistant_message` で対象メッセージを取得する。
- 返された `message.id` と `claimId` を、返信・保留・完了・変更操作に使う。
- メンバー問い合わせを起点にした変更操作では `sourceMessageId: message.id` と同じ `claimId` を指定する。直接タスクでは指定しない。
- サーバーは、問い合わせの発行者が管理者か、グループの操作許可があるかを確認する。

直接タスクの権限と、メンバー問い合わせの発行者権限は混同しない。運営支援AIキーはグループ専用であり、他グループには利用できない。

キーを共有した場合は発行者本人以外も同じ権限で操作できるため、環境ごとにキーを分け、漏えい時はグループ設定から無効化して再発行する。
