# シフト割当プレビュー

## 目的

対象期間の勤務枠、必要人数、各メンバーの基本勤務条件、期間限定の希望とコメントをまとめ、公開前の割当案を作る。これは提案であり、公開や確定割当は行わない。

## 必須の取得

管理者が発行した **運営コンテキスト** をその回だけ使用し、次を取得する。

1. `list_shift_plans` で対象シフトを特定する。
2. `get_shift_plan` で勤務枠、担当、必要人数、既存割当を取得する。
3. `get_shift_request_overview` で全在籍メンバーの以下を取得する。
   - 希望枠と希望状態
   - 今回限りの希望コメント
   - 基本勤務希望、曜日別の勤務可能時間
4. 必要なら `get_work_records` で直近の勤務量を確認する。取得できない情報は「未確認」とする。

## 判断順序

1. **満たすべき条件**: 同時刻・同担当の必要人数、同一人の重複割当の回避、勤務不可の回避。
2. **強い希望**: 出勤希望、休み希望、時間指定、今回コメントに明示された事情。
3. **調整条件**: 勤務日数・時間の偏り、連勤、夜間や日跨ぎ勤務、希望外割当。
4. **不足時**: 無理に埋めず、不足枠と理由を明示する。

今回コメントは参考情報である。「10時間以内」「連勤を避けたい」などを、管理者の確認なく厳密な自動制約へ変換してはいけない。

## プレビューの出力

各案には次を含める。

- 担当・日時ごとの割当案と不足数
- メンバーごとの予定勤務日数・時間、希望外割当数
- 警告: 不足、過剰、重複、連勤、勤務時間の偏り、勤務不可、希望無視
- コメントを採用・保留・見送りにした理由
- 管理者が確認すべき点

`workspace/reports/` には氏名を必要最小限にした要約だけを保存する。詳細案はKINBAN画面またはその回の会話で確認する。

## 禁止事項

- `set_shift_assignments` による確定保存、シフト公開をしない。
- 運営コンテキストなしに全メンバーの希望を取得しようとしない。
- 管理者メモや評価情報を割当根拠に含めない。
