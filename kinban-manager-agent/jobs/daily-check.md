# 日次確認ジョブ

## 入力

- 対象グループID
- 当日の日付（Asia/Tokyo）
- 管理者が発行した運営コンテキスト。ない場合はコンテキストなしの確認範囲に限定する。

## 実施内容

- 未処理メッセージ、当日の公開済みシフト、希望締切、勤怠異常候補を確認する。
- `skills/kinban-daily-operations/SKILL.md` に従い、変更なしのレポートを作成する。

## 出力

- `workspace/reports/YYYY-MM-DD-daily-check.md`
- 異常なし、要確認、情報不足の区分

## 成功条件

- 変更・送信・承認・公開を実行していない。
- 要確認事項に期限または影響がある。

## 失敗時

- 認証・コンテキストの失敗は一度だけ記録し、再試行の連打をしない。
