# KINBAN 認証・認可境界

## 人間の入口

- ChatGPT認証、Google認証、招待URL認証は、サイト利用者の本人性を確立する入口です。
- サイト管理者はサイト利用者・招待・グループ作成権限を管理します。
- グループ内の代表管理者・管理者・メンバー権限は `group_members` を正とします。

## API/MCPの入口

- 個人用キー: 発行されたグループの本人操作に限定する。
- 運営支援AIキー: 発行グループの管理者向け操作を、グループごとのAI権限設定に従って実行する。
- APIキーの値はハッシュ化して保存し、画面・ログ・Issue・ドキュメントへ出さない。

## 書き込み保護

- 破壊的操作や重要操作は `confirm: true` を要求する。
- バージョン競合があり得る更新は `expectedVersion` を要求する。
- メッセージ処理はclaimIdとsourceMessageIdを検証し、別workerのclaimを使えないようにする。
- 公開、承認、差戻し、削除、全体通知は監査ログへ記録する。
- AIからの提案と人間の確定操作を区別し、権限エラーをプロンプトだけで回避しない。

## 確認時のルール

対象グループ、対象期間、現在状態、対象ID、versionを読み取り、変更内容を提示してから書き込む。401/403はキーを再発行する前に、ログイン利用者・グループ所属・scope・AI権限を確認する。
