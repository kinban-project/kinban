# KINBAN 管理者ガイド

対象読者は、グループ内でシフト・勤務申告・連絡を管理する「代表管理者」「管理者」です。サイト全体の利用者や認証を管理するサイト管理者向けではありません。

## 日常運用の流れ

1. **グループ管理**で参加状況、表示名、役割、利用停止状態を確認する。
2. **シフト作成**で期間、営業時間、担当、必要人数、受付期限を設定する。
3. 受付中にメンバーの希望提出状況を確認する。未提出者がいる場合は連絡する。
4. **シフト割当**で希望、基本設定、担当、前回の偏り、店舗ルールを確認し、枠へ割り当てる。
5. 不足、重複、長時間、インターバル、希望との差分を確認して保存する。
6. 内容を確認してから**公開**する。公開後の変更は履歴を残す前提で行う。
7. **シフト一覧**でメンバーから見える担当・休憩予定を確認する。

## 勤務申告と承認

- メンバーは打刻を補助情報として使い、勤務申告の開始・終了・休憩・備考を確認して申請します。
- 過去日の申告漏れ、病欠、遅刻、早上がり、延長は備考と時刻を確認します。
- **日次承認**では、予定との差分、備考、未申告、要確認を確認します。差戻し時は理由を入力します。
- **月次承認**では、メンバー単位の月間合計、未申告日、シフト外、日次の未処理を確認して承認します。
- 月次承認済みの勤務記録はロックされます。修正が必要なら管理者が月次承認を解除し、本人の再申告を待ちます。

## 判断のポイント

- 人数不足は公開前に解消する。公開後の不足は変更履歴を残して補充する。
- 同じ時間帯の複数担当へ同じ人を割り当てない。
- 希望は優先材料であり、必要人数・担当・労務注意・公平性と合わせて判断する。
- 店舗固有のルールは**業務ガイド**に記載し、AIや次回の割当でも参照できるようにする。

## お知らせ・連絡・業務情報

- **お知らせ**はメンバー側が読む全体・個別の連絡です。管理者は**お知らせ管理**から作成、配信状況確認、既読状況確認、削除を行います。
- **連絡対応**はメンバーから管理者へ届いた問い合わせや欠勤連絡を処理する画面です。確認するメンバーを選び、返信または対応済みにします。
- メンバー側の**お知らせ**は自分宛ての未読確認と返信に使い、管理者側の**お知らせ管理／連絡対応**とは導線と権限が異なります。
- **業務ガイド**は管理者が編集・公開するMarkdownの手順、ルール、FAQです。画像を添付する場合は個人情報や不要な機密を含めない。
- **業務メモ**は原則として本人と管理者が閲覧する日報・課題・改善メモです。全員への共有はお知らせまたは業務ガイドを使う。

## 重要操作

公開、日次・月次承認、差戻し、月次承認解除、利用停止、退会、全体通知は、対象と内容を確認してから実行します。迷ったら操作ログと対象画面を確認し、AIにはまず調査・下書きを依頼します。
