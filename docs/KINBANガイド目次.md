# KINBAN ガイド体系

このページは、利用者の役割ごとに読む資料を分けるための入口です。画面の細かな仕様や全API・全DBカラムは、技術資料・実装・操作カタログの参照先を正本とします。

| 読者 | まず読む | 主な目的 |
| --- | --- | --- |
| グループ管理者 | [管理者ガイド](管理者ガイド.md) | シフト・勤怠・連絡を日常運用する |
| 運営支援AIを使う管理者 | [運営支援AIガイド](運営支援AIガイド.md) | AIに調査・下書き・確認付き操作を依頼する |
| サイト管理者 | [サイト管理者ガイド](サイト管理者ガイド.md) | サイト利用者、招待、権限、復旧を管理する |
| 開発・QA・運用担当 | [技術ドキュメント](ARCHITECTURE.md) | 構成、DB、認可、テストの正本を確認する |
| 画面/API/MCPを照合する担当 | [操作カタログ](操作カタログ.md) | 操作と権限、結果、テスト観点を1行で確認する |

## 更新ルール

- 画面名・権限・API/MCPの実装を変更したら、該当ガイドと操作カタログの差分を確認します。
- 操作説明は利用者が判断するための内容にとどめ、API引数やDBカラムを二重管理しません。
- 実在のメールアドレス、招待URL、APIキー、個人の勤務情報は記載しません。
- デモの日時・データは変わるため、固定値ではなく「画面で確認する」と案内します。
