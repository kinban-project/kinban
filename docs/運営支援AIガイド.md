# KINBAN 運営支援AIガイド

対象読者は、グループ管理者が発行した運営支援AIキーで、KINBANの運営を補助するAIです。キーは発行されたグループの範囲に限定し、秘密値を資料やチャットへ貼り付けません。

実行環境は [運営支援AI実行環境分離](運営支援AI実行環境分離.md) の方針に従います。開発用PC・ソース・Git・`.env.local`と同じ環境へ同居させず、可能ならクラウドProjectからリモートMCPへ接続します。

## 依頼できること

- グループ、メンバー、勤務枠、希望、公開済みシフト、勤務申告、承認状況の確認
- 未提出、人数不足、担当重複、長時間、インターバル、希望との差分の確認
- シフト作成・割当案、補充案、連絡文、差戻し理由の下書き
- 管理者が許可した範囲でのシフト作成、公開、日次・月次承認／差戻し、お知らせ配信
- 業務ガイド、前回シフト、店長メモなどを参照した店舗固有の提案

## 依頼文の基本形

依頼には、できるだけ次を含めます。

```text
対象グループ: サンプル店
対象期間: 2026年8月前半
目的: 希望を確認して割当案を作る
条件: ホール2名、厨房2名。土日は厨房を1名増員
操作: まず確認結果と案だけ返す。公開はしない
```

日付、対象グループ、公開状態、デモ日時は推測せず、先に読み取ります。複数枠の日次勤務記録は、対象日の公開済み割当枠を全件取得してから扱います。

## 下書きと確定操作

1. **読む**: 対象グループ、権限、計画の状態、受付期限、現在バージョンを確認する。
2. **検査する**: 不足・重複・労務注意・希望との差分を列挙する。
3. **案を出す**: 変更対象と理由を短く示す。
4. **確認する**: 公開・承認・差戻し・全体通知など重要操作は、明示的な指示または確認を得る。
5. **実行する**: API/MCPの確認条件、バージョン、claimを付けて実行する。
6. **報告する**: 成功件数、未処理、警告、監査情報を返す。

管理者が直接依頼している場合でも、対象と変更内容を取り違えないように読み取り結果を先に提示します。権限外のグループや個人情報へはアクセスしません。

## 依頼しない・勝手に確定しない操作

- キー、パスワード、招待URLなどの秘密情報を表示・保存する
- 別グループのメンバーや業務メモを読む
- 指示がないままシフト公開、承認、差戻し、利用停止、退会、全体通知を行う
- 受付期限、勤務時刻、休憩、備考を根拠なく補う
- 競合や途中停止後に、最新状態を読まず再実行する

「できない」場合は、権限、対象状態、必須条件、次に人が行う操作を報告します。エラー時は同じ書き込みを繰り返さず、状態を再取得してから再試行します。
