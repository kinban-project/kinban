# シフト・勤怠 業務受入テスト

実施日: 2026-07-19

このフォルダは、シフト・勤怠管理を実際の店舗業務として検証するための成果物一式です。アプリ本体のコードは変更せず、ローカルD1だけをテスト対象にします。

## 構成

- `TEST_PLAN.md`: 方針、対象、完了条件
- `CASES.md`: テストケースと結果
- `FINDINGS.md`: 問題と改善候補
- `FINAL_REPORT.md`: 最終まとめ
- `scripts/api-scenarios.mjs`: API業務シナリオと権限・境界テスト
- `scripts/mcp-scenarios.mjs`: MCPプロトコル／ツールテスト
- `scripts/generate-scale-seed.mjs`: 5グループ・100人規模のSQL生成（次回試験基準）
- `scripts/concurrency-scenarios.mjs`: 管理者同時更新の競合テスト
- `logs/`: 実行ログと計測結果
- `evidence/`: スクリーンショットなどの画面エビデンス

## 対象外

- アプリ本体の修正（テスト不能となるクリティカル障害のみ例外としたが、今回は該当なし）
- コーディングスタイル、共通化、命名のレビュー
- 公開環境のDB操作
- 網羅的な単体テスト追加

## 次回の規模試験

グループ数の限界条件は5グループとする。`logs/`と既存スクリーンショットには、2026-07-19に実施した10グループ試験の履歴が残っている。
